## Summary

LittleSteps can now be added to a home screen and opens like an app, while every feature still works in the browser. The service worker keeps the app shell only, never an API response, and later epics get two hooks: `offerInstall()` to ask at a good moment, and `useAppUpdate()` to apply a new version safely.

## Added

- Web app manifest (name, short name, colours read from `tokens.css`, standalone, icons) and a service worker that precaches the shell only, built by `vite-plugin-pwa` from `frontend/pwa.config.ts`.
- App icon: a simple block drawing kept as `frontend/public/icons/app-icon.svg`, with PNGs generated by `npm run icons`.
- `frontend/src/pwa/`: `offerInstall()` and the `InstallOffer` dialog (the browser's own prompt where it exists, short instructions where it does not, chosen by feature detection; not on the first visit; not again after "Not now" unless asked from Settings), and `useAppUpdate()`.
- Catalog keys `pwa.title`, `pwa.body`, `pwa.instructions`, `pwa.add`, `pwa.gotIt`.
- `viewport-fit=cover`, theme-colour metas and an Apple touch icon in `index.html` (the Story 2.8 part of deferred #125).
